# ReelVault: shared community files

This repository holds the defaults for every repository in the [ReelVault](https://github.com/ReelVault) organization, plus the organization's public profile page.

GitHub uses these files automatically for any repository that does not have its own copy:

| File | What it covers |
|---|---|
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to propose and submit a change |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | How everyone is expected to behave |
| [`SECURITY.md`](SECURITY.md) | How to report a security problem privately |
| [`.github/pull_request_template.md`](.github/pull_request_template.md) | The checklist for new pull requests |

[`profile/README.md`](profile/README.md) is the front page of the organization at [github.com/ReelVault](https://github.com/ReelVault).

## Changing a default

A repository can override any of these files by adding its own copy. A file in the repository always wins over the one here.

To change a default, edit the file here and open a pull request, following [CONTRIBUTING.md](CONTRIBUTING.md).
