All ReelVault repositories share the same ground rules. They live here, along with the organization's public profile page. GitHub applies them automatically to any repository that doesn't have its own copy, so everyone sees the same guidelines wherever they start.

## What's in this repo

| | File | What it covers |
|---|---|---|
| 📝 | [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to propose and submit a change |
| 🤝 | [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | The ground rules for everyone in the community |
| 🔒 | [`SECURITY.md`](SECURITY.md) | How to report a security problem privately |
| ✅ | [`.github/pull_request_template.md`](.github/pull_request_template.md) | The checklist for new pull requests |

[`profile/README.md`](profile/README.md) is the front page of the organization at [github.com/ReelVault](https://github.com/ReelVault).

## Changing a default

Any repository can override these files by adding its own copy. When it does, that version takes precedence.

To change a default, edit it here and open a PR — see [CONTRIBUTING.md](CONTRIBUTING.md).
