# ReelVault

A self-hosted media server: organizes your movie and TV library, streams it
over HLS with on-the-fly transcoding, and extends itself through a runtime
plugin system.

- **[reelvault](https://github.com/ReelVault/reelvault)** — the server (backend)
- **[website](https://github.com/ReelVault/website)** — web & desktop client
- **[sdk](https://github.com/ReelVault/sdk)** — typed TypeScript SDK for the client and plugins
- **[plugins](https://github.com/ReelVault/plugins)** — official plugin catalog
- **[plugin-template](https://github.com/ReelVault/plugin-template)** — fork-able starting point for a plugin
- **[reelvault.org](https://github.com/ReelVault/reelvault.org)** — documentation site

📖 Docs: **[reelvault.org](https://reelvault.org)**
